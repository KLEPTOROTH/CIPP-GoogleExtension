### Trust boundaries

1. UI -> API: untrusted input; keep typed validation + explicit error mapping.
2. API -> adapter: upstream snapshot reads are fallible; failure must be fail-closed (no mirror mutation on read failure).
3. Durable store init: no silent downgrade to in-memory unless `CIPP_ALLOW_INMEMORY_FALLBACK=true`.

## Sequence (demo-critical runtime)


Critical invariant: no downstream state mutation if upstream snapshot fetch fails during reconcile.
